# [XS] Try and promote the Network X-Ray HUD

## Goal

The maintainer has tried the Debug-mode MoQ telemetry HUD in a real room and
decided whether and how to show it off.

## Plan

Promote it once health grades land, since a colored grade per tile is what
reads at a glance; until then the HUD is a developer view.

  not at all). An agent cannot judge whether it is compelling or write the
  announcement.
